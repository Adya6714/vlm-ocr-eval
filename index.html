What does OCR confidence actually measure?

Scroll this tab as a talk. We ask whether max-softmax confidence tracks visual evidence, or only how peaked the decoder is. The claim is narrow: in a ~19.6M from-scratch instrument that does not read its held-out images, confidence stays extremely high — including at generation position 0.

PDF · BOOK · first principles

Say this first

We are not claiming that production readers ignore images. We are showing confidence without grounding in this controlled instrument — then asking what transfers.

Step 1 · what “0.90” means

Confidence is the peak of 367 probabilities — not “probability of correct”

At every decoding step the model scores every vocabulary item (~367 grapheme tokens), then softmax turns those scores into probabilities. The reported confidence is simply the largest one:

Ct = maxv P(v | image, previous tokens)

If that max is 0.90, we say “90% confident in its selected token.”

Token A is not one fixed grapheme. It is whatever wins on that image at that step — maybe क on one page, स on another. The shock is not “the model likes क.” The shock is: whatever wins is almost never the correct first grapheme.

Position-0 predictive entropy ≈ 0.333 nats (sharp, not soft). Median rank of the true grapheme ≈ 70.5 / 367; 35% of sequences put it below rank 100. The truth is pushed far down the list — not “almost right.”

Step 2 · why position 0

No previous text — so the image has to do the work

Later tokens can lean on a language prior (“after भा, next is probably र”). At position 0 there is only <BOS>. A correct first grapheme is strong evidence of using the image.

Across 180 image×seed evaluations: ground truth is the argmax 0 / 180 times · teacher-forced p(GT) ≈ 2.2×10⁻¹¹ · self-generated max-softmax ≈ 0.902. Blank looks the same qualitatively.

That is stronger than “the first token was wrong.” Mid-sequence the OCR decoder looks a lot like a model that never had an image — statistical regularities of training text, not “world knowledge.” (Probe 5 synthetic eval is also from the training manifest.)

Step 4 · competing explanations

Blank, ablation, undertraining — phrase carefully

Blank / noise / scramble

Removing visual content does not collapse the confidence peak. That is evidence confidence is not measuring visual grounding here. It does not prove the model learned vision and then ignored it — it may never have learned a useful visual representation. The paper keeps that alternative alive.

Encoder ablation

Zero visual memory: confidence barely moves (0.986 → 0.989). But the distribution does change (KL ≈ 1.075; ~8% argmax flips). Better sentence: vision can change which token wins sometimes; the max-softmax scalar is largely insensitive. Do not say “the model doesn’t use vision.”

Undertrained?

Yes — ~19.6M, 5k steps. We do not claim the architecture cannot read. We claim: under this regime it did not acquire reliable reading, while confidence stayed high. Training curves, unseen scripts (0 target-script chars / 360), and the position profile attack that story from other angles. A positive-control reader is still Priority 1.

Step 5 · 60-second answer

If they ask about position 0 — say this

Open in a call

Position 0 removes the language-prefix confound. Across 180 evaluations the correct first grapheme was never the argmax, yet max probability was around 0.90 and ground-truth probability around 2×10⁻¹¹.

We didn’t stop there. Position 1 is still poor; from positions 2–39 the model recovers to a regime very close to a text-only 4–5-gram, with 91–94% argmax agreement. So the decoder can generate predictable text from linguistic regularities even when the image isn’t providing useful grounding.

Blank images don’t collapse confidence — but I wouldn’t claim we proved “learned vision, then ignored it.” The model may simply be undertrained. That’s why a positive-control reader is the next experiment.

Can confidence tell us when Indic OCR is hard?

Sarvam Vision already publishes large language-wise gaps on its Indic OCR bench. The practical question is whether an exposed confidence field moves with that difficulty — and whether a controlled diagnostic of “confidence vs grounding” transfers to production pages. Mechanism lives on Diagnosis.

Why the instrument exists

Sarvam is the production reference. The toy is for counterfactuals.

Relationship is not “our OCR vs Sarvam OCR.” It is:

Sarvam Vision = external production system
        ↑
   “Does any diagnosis transfer?”
        ↑
~19.6M controlled instrument
        ↓
blank · unseen script · encoder ablation · position-0 p(GT)

An API can tell you what it outputs. It cannot let you remove the image, zero visual memory, or score the true first grapheme under teacher forcing. That is why the instrument was built — then Stage 5 asks what, if anything, transfers.

Stage 5b & 6 · after the preprint

No per-image transfer. Triage worse than random.

We did not expect absolute CERs to match a 3B-class system. We tested whether difficulty ranking transfers (Spearman, permutation null locked before looking).

5b primary: Hindi plains, n=60 → ρ = 0.0293, p = 0.8267 — genuine null. Instrument hard pages ≉ Sarvam hard pages.

6 fair slice: escalate 20% (k=12). Residual system CER — instrument confidence 0.0109, random 0.0095, GT length 0.0092, Tesseract confidence 0.0079. Max-softmax from the instrument is not a useful router here.

Budget: degraded secondary underpowered (HTTP 402). Do not treat underpowered arms as confirmed nulls the way n=60 primary is. Reports: stage5b · stage6.

What this contributes

A controlled decomposition of confidence — and a production null

One-paragraph pitch for the call:

We built a controlled OCR instrument to decompose confidence into visual evidence versus language-prior behavior — experiments that are hard on a production API (blank, unseen script, encoder ablation, position-resolved teacher-forced likelihood, text-only n-gram baselines). Max-softmax could remain near ceiling while the correct first grapheme had ~10⁻¹¹ probability. We then tested transfer to Sarvam Vision at language level and per-image level; we found no useful per-image transfer in this sample. The lesson is not “confidence is useless.” It is that max-softmax is not necessarily a grounding signal, so the next generation of OCR confidence should measure visual contribution explicitly.
