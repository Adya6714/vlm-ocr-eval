Confidence Without Sight

Token-level confidence in autoregressive OCR can remain near ceiling when visual evidence is removed, when encoder memory is zeroed, and when the script is unseen — even as recognition accuracy collapses.

Claim. Decoder confidence is widely treated as a proxy for visual certainty. This work tests that proxy on a blank Indic OCR instrument: if confidence tracked the image, it would fall on blank and matched-noise inputs, after encoder memory is deleted, and on scripts never seen at training time.

Method. A ~19.5M-parameter encoder–decoder with a grapheme-cluster vocabulary and no Indic pretraining is trained on exposure-controlled line crops (natural / flattened / inverted). Probes then measure real versus blank versus matched-noise confidence, a training-curve disambiguation, calibration and zero-shot script substitution, encoder-memory ablation, and held-out real-scan transfer. Scoring applies grapheme-aware encoding equivalence before residual error is counted.

Finding. On Hindi, mean confidence is 0.9940 on real lines versus 0.9899 on blanks (gap +0.0041). Across training, the real–blank gap is indistinguishable from zero while loss falls ~18× (3.210 → 0.182). Zeroing encoder memory changes mean confidence by −0.0030; ~12% of token-choice mass remains image-dependent. On held-out real scans, line accuracy is 0.0000 at confidence 0.9861 (plain) and 0.9768 (degraded). Probe 5b (720 records, three seeds) finds a between-condition confidence range of 0.0037, below Hindi seed SD (0.0043). Content and confidence are dissociated.

Not a competing OCR — a mechanism question for Sarvam Vision

Probing Sarvam Vision: why does confidence stay flat across a 40-point accuracy gap?

Sarvam’s own published word accuracy is Hindi 95.91 / Kashmiri 55.93 (a 39.98 pp gap). Live Extract-API confidence on the same three languages is Hindi 0.9997 / Kashmiri 0.9970 (delta 0.0027; Santhali 0.9974). I built this for a conversation at Sarvam, not as a generic OCR landing page. You already publish the Hindi–Kashmiri accuracy gap. Chapter 0 · Why reading is hard
Introduction

A machine does not see letters; it sees numbers

OCR as sequential prediction over a pixel grid

A page is a grid of RGB values. Modern readers generate text one visual unit at a time from that grid. English clean-print OCR is mostly solved; Indic document OCR is not — for three tangled reasons.

A page is a grid of RGB values. An autoregressive reader emits one visual unit at a time from that grid. Clean-print English OCR is largely solved; Indic document OCR is not, for three entangled reasons.

Data

Training data is dominated by high-resource languages. A model can only get good at reading what it has seen enough of.

Script structure

Conjuncts, matras, and the shirorekha are a different geometric problem than Latin. One visual grapheme cluster can be many Unicode code points.

Causes tangle

A low language score could be exposure starvation, intrinsic difficulty, or both. A benchmark table alone cannot tell which — untangling requires controlling training exposure and owning the model.

That single sentence is the entire reason this project builds a model from scratch rather than only ever calling someone else’s API.

Untangling those causes requires controlling training exposure and inspecting decoder internals; a closed API cannot supply either.

Chapter 1 · Measuring correctness
Method · Evaluation

When two strings differ — is that a real misread?

Equivalence-aware evaluation

Indic orthography allows many valid encodings. If you call those “errors,” every engine looks worse than it is. Stage 0 forces that answer into the open before anyone trains a new model.

Indic orthography admits multiple valid encodings of the same reading. Treating those as errors inflates every engine’s residual. Encoding and phonetic equivalence are therefore recorded before any new model is trained.

Tier 1 — encoding

Deterministic, uncontroversial. Same reading, different bytes. Hand-curated tables in equivalence_tables.py.

Tier 2 — phonetic

A judgment call via ISO 15919 transliteration. Reported separately so arguable matches never inflate encoding noise.

Human residual

Genuine misread, dropped matra/nukta, order break, hallucination — or explicit no-fit. Alignment at grapheme clusters, not code points.

Chapter 7 · The probes
Method · Probes

We built the model so we can open it up

Diagnostic probes

Accuracy tells almost nothing about how the model arrived there. Think of the instrument as a patient in a lab, and the probes as medical tests. They are the project’s real deliverable.

Accuracy does not identify the computation that produced it. The probes are the primary measurements: exposure, confusion, visual grounding, calibration, encoder-memory ablation, and held-out real-scan transfer.

1 · Exposure — does seeing more help?

Nine runs: natural / flattened / inverted × three seeds. Plot accuracy vs log exposure; residual after exposure is a candidate for intrinsic visual complexity.

2 · Confusion — what did it almost say?

GT-aligned substitutions plus p(true) and rank. Closed APIs often return only the top string. BUILT — VERIFIED, 3 seeds.

3 · Grounding — is it looking?

Real / blank / matched noise, plus a training-curve disambiguation (3b). Fluent high confidence on blank is language-prior guessing. BUILT — VERIFIED, 3 seeds.

Ablation · Does confidence need the image?

Zero encoder memory before projection. Confidence barely moves (Δ −0.0030) while ~12% of token-choice mass still depends on the image. Content and confidence are dissociated. BUILT — VERIFIED, 3 seeds.

4 · Fair scoring

Same Tier 1/2 rules on instrument outputs as on Tesseract.

5 · Calibration — can I trust confidence?

5 · Calibration — does confidence track correctness?

Especially on starved glyphs (Probe 1 × 5). Probe 5b is the zero-shot floor on unseen scripts. BUILT — VERIFIED (5b: 720 records, 3 seeds).

6 · Reality check

Do synthetic findings hold on Tier C real documents? Paper-scope Probe 6: held-out Hindi, leakage-checked, 3 seeds. BUILT — VERIFIED.

Measured results

Attention ablation — MEASURED (Claim B mechanism)

3 seeds, 180 Hindi Tier C images. Mean confidence full 0.9861 vs zero-memory 0.9891 (Δ −0.0030). Top-1 agreement 0.8794; prior sufficiency 0.8827 (~12% of token-choice mass still depends on the image). Confidence is prior-dominated; content is not 100% prior.

Probe 3 / 3b — MEASURED (3 seeds)

Natural pooled: real 0.9940 · blank 0.9899 · noise 0.9904 (gap +0.0041). Training curve: real−blank gap sign-flips 4/5 steps, |SD|>|mean| 4/5, while loss falls ~18× (3.210 → 0.182). Undertraining and ungrounded confidence are not competing explanations.

Probe 5 / 5b — MEASURED (3 seeds)

Natural: ~99% confidence, line accuracy 14–24%, ECE ≈ 0.81. Probe 5b: 720 records; between-condition range of seed means 0.0037 < hindi seed SD 0.0043. Script substitution 360/360. Seed-0 Kashmiri-vs-Hindi “significance” is retracted (does not replicate).

Probe 6 — MEASURED (3 seeds, leakage-free)

Held-out Tier C Hindi: 0 overlaps with training manifests. Confidence real_plain 0.9861 · real_degraded 0.9768 · blank 0.9799; Tier 1/2 line accuracy 0.0000. Claim B is not a synthetic-only artifact.

Related Work / Motivation

Non-silent failure, and a synthetic–real split

Two published facts motivate a blank instrument rather than another engine table.

GlotOCR Bench

Production OCR systems fail non-silently at true zero script exposure: confidence stays high when the script in the image is one the model has never seen (Probe 5b motivation).

2026 Devanagari stress-test

Ten systems cluster tightly on clean synthetic text but spread across a 76-point range on real scans. A synthetic-only finding is not a document finding.

What was then built

A blank instrument plus blank/noise, training-curve, encoder-memory ablation, and held-out Tier C probes, so that whether confidence depends on the page can be answered without a closed API.

Implications

Step back from the modules. Three implied fixes — and what is deferred, not abandoned.

Three implications follow from the measured probes. Components listed as deferred are out of scope for this phase, not abandoned.

1 · Score fairly

Score Indic OCR with grapheme-aware, Tier-1-aware metrics. On the order of one in five of Tesseract’s non-exact preds can be encoding variants — not wrong readings.

2 · Design exposure

Treat glyph exposure as something you design (natural / flattened / inverted, TV ≤ 0.08), not something you observe after the fact.

3 · Trust calibration

Treat fluent, high-confidence failure as a calibration and routing problem — not only as “need more accuracy.”

The demo, RLVR, full transfer rank-correlation, and cascade are how those questions eventually meet production systems; Stage 5a is the first cached contact. The rest are deferred, not abandoned.
